# 📸 Vintage Photobooth - Nostaljik Fotoğraf Kabini

Kullanıcıya gerçek bir retro fotoğraf kabini deneyimi yaşatan; perde geçişi, canlı kamera çekimi, nostaljik filtreler ve çıkartmalarla donatılmış interaktif web uygulaması.

---

## ✨ Öne Çıkan Özellikler

- 🎬 **Retro Video & Perde Geçişi:** Kabin perdesini aralayarak başlayan sinematik giriş ve geri sayım deneyimi.
- 📷 **Gerçek Zamanlı Kamera Çekimi:** Web kamerası üzerinden anlık 4'lü fotoğraf serisi (Photo Strip) yakalama.
- 🎞️ **Vintage & Retro Filtreler:** Nostaljik siyah-beyaz, sepya ve vintage renk tonlamaları.
- 🎨 **Çıkartma & Meme Galerisi:** Fotoğraf şeridinize ekleyebileceğiniz eğlenceli çıkartmalar ve popüler meme'ler.
- 🖨️ **Baskı & İndirme Simülasyonu:** Hazırlanan fotoğraf şeridini fiziksel kabin çıktısı gibi kaydetme ve indirme.

---

## 🛠️ Kullanılan Teknolojiler

- **Frontend:** HTML5, CSS3 (Custom Responsive Layouts), Vanilla JavaScript
- **Medya API:** WebRTC MediaDevices API (Camera Capture)
- **Grafik & Çizim:** HTML5 Canvas API (Fotoğraf birleştirme ve filtreleme)

---

## 🚀 Çalıştırma

Web kamerası izinlerinin düzgün çalışabilmesi için projeyi bir yerel sunucu ile başlatın:

```bash
# Python ile hızlı yerel sunucu:
python3 -m http.server 8000
```
Tarayıcınızda `http://localhost:8000` adresine gidin ve kameranızı açarak kabine adım atın!
